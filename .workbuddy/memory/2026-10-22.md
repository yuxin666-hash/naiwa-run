# 2026-10-22

## 奶蛙桌宠（Windows 桌面宠物）— 首个完整版本

**需求**：用 `奶蛙-clean.png` 做一只可放在桌面的桌宠。用户选择：丰富互动、程序化动效（不额外补帧）、中号约 180px、托盘常驻 + 开机自启。

**技术方案**（零第三方 GUI 依赖，仅 Pillow + 标准库）：
- `app/win.py`：ctypes 直接调 Win32。分层窗口 `UpdateLayeredWindow` + 32bpp 预乘 BGRA（PIL `convert('RGBa').tobytes('raw','BGRa')`）实现真逐像素透明；`WM_NCHITTEST` 查像素 alpha 返回 `HTTRANSPARENT`，实现透明区域点击穿透；`WM_MOUSEACTIVATE` 返回 `MA_NOACTIVATE` 不抢焦点；`Shell_NotifyIconW` 托盘；`CreatePopupMenu/TrackPopupMenu` 原生中文菜单；`winreg` 写 HKCU Run 做自启。
- `app/art.py`：按目标高度缩放立绘、绕脚底锚点做仿射变换（只在包围盒上算，`Image.Transform.AFFINE`）、气泡 2 倍超采样、爱心/饼干程序化绘制。
- `app/main.py`：行为状态机 idle/walk/look/jump/pat/eat/drag/fall/land/sleep，帧率分档 30/24/10fps，所有淡出用 256 项 LUT（避免逐像素 lambda，此坑把 CPU 从 48% 打到 15%）。
- `tools/build_assets.py`：抠图。要点：背景判定用「颜色距离」+「背景色按比例变暗（ratio 三通道接近）」两种，从四边泛洪，两腿之间的暗奶油色空洞才能被吃掉；alpha 先 `MinFilter(3)` 再 `GaussianBlur`，避免奶油色描边；颜色向透明区外扩 10 圈去边缘彩边。
- 闭眼是用环形采样色 + 局部大半径模糊得到的低频光影盖住眼球，再叠 4 倍超采样的眼线；素材原图眼睛中心 (438,233) r≈33，远侧眼 (356,240)，嘴 (405,296)。
- `tools/make_shortcut.py`：ctypes 走 COM(IShellLinkW/IPersistFile) 生成 .lnk。vtbl 下标：SetDescription 7 / SetWorkingDirectory 9 / SetArguments 11 / SetShowCmd 15 / SetIconLocation 17 / SetPath 20；IPersistFile::Save 是 6。

**环境注意**：
- 本机 150% DPI，窗口尺寸按 `GetDpiForSystem()/96` 换算，否则中号只有 120 逻辑像素。
- 沙箱内 APPDATA 与注册表是"影子视图"：应用自己写的自启项在真实系统里看不到，需用 PowerShell 落真实注册表。
- 系统 Python 3.10（`C:\Users\喻欣\AppData\Local\Programs\Python\Python310`）有 Pillow 12 + numpy；托管 3.13 没有 tkinter/PIL。

## 追加：单击改为「捧腹大笑」

- 交互变更：单击（`on_up` 位移 < 7px）由 `pat()`（摸头）改为 `laugh()`；摸头仍保留在右键菜单，另加「捧腹大笑」菜单项 `M_LAUGH=1005`。
- 新增贴图 `assets/frog_laugh.png`（597x1198）：在 `frog_closed.png` 上把原嘴线局部柔化，按 `tools/build_laugh.py` 画一张张开的嘴（深色口腔 + 上颚阴影 + 裁进嘴型的舌头 + 上唇高光），4 倍超采样后叠回，仅作用于嘴附近皮肤区域。
- 状态机加 `laugh`（2.3s）：前仰后合 `angle=5°·sin(11t)`、上下颠 `dy`、挤压 `sy/sx`，渲染时 `state=="laugh"` 直接用 `sprite.laugh`。
- 头顶不再放字（会和气泡打架），「哈」贴片改为从身体两侧往斜上方飘：`art.ha_glyph()` 用蒙版膨胀做奶油光晕 + 实心珊瑚色字形；淡出仍走缓存 LUT。
